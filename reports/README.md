The complete existing-environment acceptance log was observed locally, but a full textual log is not bundled unless explicitly exported.

**Limits:** fixed-date snapshots, single machine, uncached Metabase API query latency—not full browser rendering or future-date correctness. The source simulator must be stopped and downstream CDC caught up for strict reconciliation.
